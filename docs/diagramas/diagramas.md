# Diagramas do Sistema

## Principais Modelagens e Fluxos
- **Diagrama de Arquitetura de Dados:** Mapeia a jornada da informação desde os sensores de campo até o banco PostgreSQL e os disparos de alerta no painel web.
- **Diagrama de Casos de Uso / Fluxo Operacional:** Descreve a interação dos operadores da concessionária com o mapa interativo dos setores (ex: setores A1 a C2) e as opções de resposta a incidentes (abertura de ordens de serviço e fechamento remoto de registros).
